# Эмулятор оболочки: вариант 25

Практическая работа по конфигурационному управлению, вариант 25
из файла «УНБО-04-25.pdf», страницы 80–81. Реализация на Python,
без сторонних библиотек. Подключена загрузка VFS третьего этапа.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```powershell
python src/main.py
python src/main.py --vfs examples/files.csv --script examples/startup.txt
```

В Windows можно использовать `run.bat` с теми же параметрами.

## Этап 1: ввод команд

Консольная оболочка показывает приглашение с именем VFS и разбирает
команды с помощью `shlex.split()`. Синтаксис: `ls [путь]`, `cd [путь]`, `exit`.
`ls` и `cd` пока являются заглушками: показывают название и аргументы,
не читают файлы и не меняют папку. `exit` завершает работу.
Одинарные и двойные кавычки поддерживаются: `ls "/my docs"` передает
один аргумент `/my docs`. Подстановка переменных не выполняется.
Незакрытые кавычки вызывают ошибку разбора.

Неизвестная команда и лишние аргументы вызывают сообщение об ошибке.
При ручном вводе после ошибки можно продолжить работу.

Пример запуска без параметров:

```text
vfs:/$ ls
ls: аргументы = []
vfs:/$ cd /docs
cd: аргументы = ['/docs']
vfs:/$ ls "/my docs"
ls: аргументы = ['/my docs']
vfs:/$ unknown
Ошибка: неизвестная команда: unknown
vfs:/$ ls a b
Ошибка: ls: допустим один путь
vfs:/$ exit
```

## Этап 2: настройки и файл команд

`--vfs` задает путь к CSV-файлу VFS. Начиная с третьего этапа файл
загружается и проверяется. Если параметр не указан, создается пустая
VFS с именем `vfs` в памяти; файл на диске не требуется.
Имя загруженной VFS берется из имени CSV без расширения.

`--script` задает путь к стартовому файлу команд. Если параметр
не указан, программа сразу переходит к ручному вводу.
Оба выбранных параметра показываются при запуске.

В стартовом файле каждая строка содержит одну команду. Программа
показывает приглашение, команду и результат, как при ручном вводе.
Пустые строки разрешены. Ошибочная строка вызывает сообщение с номером
строки и пропускается: следующие команды продолжают выполняться.
`exit` завершает работу с кодом 0. Если файл закончился без `exit`,
начинается ручной ввод. Ошибки отдельных команд не дают код 1.
Отсутствующий или нечитаемый файл команд также дает код 1.
Ошибочные параметры запуска отклоняются `argparse` с кодом 2.

`examples/startup.txt` содержит успешный пример с `exit`.
Файлы `examples/error_*.txt` проверяют неизвестную команду,
неправильные аргументы `ls`, `cd`, `exit` и незакрытые кавычки.
После ошибки выполняется команда с путем `/after-error`, затем `exit`.

## Основные функции

- `parse_args()` читает параметры запуска.
- `main()` создает оболочку и выбирает режим работы.
- `Shell(name, output, vfs)` задает имя, место вывода и объект VFS.
- `Shell.prompt` формирует приглашение к вводу.
- `Shell.execute(line)` разбирает одну команду и выполняет ее.
- `Shell.repl()` повторяет ручной ввод команд.
- `Shell.run_script(path)` выполняет команды из файла.

## Проверка

```powershell
python -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File scripts/test_config.ps1
powershell -ExecutionPolicy Bypass -File scripts/test_errors.ps1
```

Тесты Python проверяют команды, кавычки, приглашение, параметры запуска,
выполнение файла и продолжение после ошибок. `test_config.ps1` проверяет
разные пути VFS, наличие и отсутствие параметра стартового файла.
`test_errors.ps1` проверяет неверные команды и отсутствующий файл команд.

## Файлы проекта

- `src/main.py` — запуск и настройки.
- `src/shell.py` — оболочка и обработка команд.
- `tests/` — автоматические проверки Python.
- `examples/` — текстовые файлы команд.
- `scripts/` — проверочные скрипты Windows.
- `run.bat` — запуск программы в Windows.

## Ход третьего этапа

Добавлен отдельный модуль `src/vfs.py`: загрузка CSV в память,
проверка путей и родителей, текст UTF-8 и данные base64, чтение `/motd`.
Формат CSV: `path,type,encoding,data`. Корень `/` создается автоматически;
папка хранится как `None`, файл — как байты. Добавлены примеры минимальной,
обычной и вложенной VFS и тесты загрузчика. Загрузка подключена к запуску:
ошибки дают код 1, без `--vfs` создается VFS в памяти, текст корневого
файла `/motd` показывается до команд. `ls` и `cd` остаются заглушками.
