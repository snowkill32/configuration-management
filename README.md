# Эмулятор оболочки: вариант 24

Практическая работа по конфигурационному управлению, вариант 24
из файла «УНБО-04-25.pdf», страницы 77–78. Реализация на Python,
без сторонних библиотек. В текущей версии выполнены этапы 1 и 2.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```powershell
python src/main.py
python src/main.py --vfs demo.xml --script examples/startup.txt
```

В Windows можно использовать `run.bat` с теми же параметрами.

## Этап 1: ввод команд

Консольная оболочка показывает приглашение с именем VFS и разбирает
команды по пробелам. Синтаксис: `ls [путь]`, `cd [путь]`, `exit`.
`ls` и `cd` пока являются заглушками: показывают название и аргументы,
не читают файлы и не меняют папку. `exit` завершает работу.
Кавычки и подстановка переменных не поддерживаются.

Неизвестная команда и лишние аргументы вызывают сообщение об ошибке.
При ручном вводе после ошибки можно продолжить работу.

Пример запуска без параметров:

```text
vfs:/$ ls
ls: аргументы = []
vfs:/$ cd /docs
cd: аргументы = ['/docs']
vfs:/$ unknown
Ошибка: неизвестная команда: unknown
vfs:/$ ls a b
Ошибка: ls: допустим один путь
vfs:/$ exit
```

## Этап 2: настройки и файл команд

`--vfs` задает путь к VFS. По умолчанию это `vfs.xml` в папке проекта.
На втором этапе путь только сохраняется и выводится: файл VFS
не открывается, его наличие не проверяется. Имя для приглашения
берется из имени файла без расширения: `demo.xml` дает `demo:/$`.

`--script` задает путь к стартовому файлу команд. Если параметр
не указан, программа сразу переходит к ручному вводу.
Оба выбранных параметра показываются при запуске.

В стартовом файле каждая строка содержит одну команду. Программа
показывает приглашение, команду и результат, как при ручном вводе.
Пустые строки разрешены. Первая ошибка останавливает выполнение
с кодом 1; строки после ошибки не выполняются. `exit` завершает
работу с кодом 0. Если файл закончился без `exit`, начинается ручной ввод.
Отсутствующий или нечитаемый файл команд также дает код 1.
Ошибочные параметры запуска отклоняются `argparse` с кодом 2.

`examples/startup.txt` содержит успешный пример с `exit`.
Файлы `examples/error_*.txt` проверяют неизвестную команду
и неправильные аргументы `ls`, `cd` и `exit`.

## Основные функции

- `parse_args()` читает параметры запуска.
- `main()` создает оболочку и выбирает режим работы.
- `Shell(name, output)` задает имя оболочки и место вывода сообщений.
- `Shell.prompt` формирует приглашение к вводу.
- `Shell.execute(line)` разбирает одну команду и выполняет ее.
- `Shell.repl()` повторяет ручной ввод команд.
- `Shell.run_script(path)` выполняет команды из файла.

## Проверка

```powershell
python -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File scripts/test_config.ps1
powershell -ExecutionPolicy Bypass -File scripts/test_errors.ps1
```

Тесты Python проверяют команды, приглашение, параметры запуска,
выполнение файла и остановку на ошибке. `test_config.ps1` проверяет
разные пути VFS, наличие и отсутствие параметра стартового файла.
`test_errors.ps1` проверяет неверные команды и отсутствующий файл команд.

## Файлы проекта

- `src/main.py` — запуск и настройки.
- `src/shell.py` — оболочка и обработка команд.
- `tests/` — автоматические проверки Python.
- `examples/` — текстовые файлы команд.
- `scripts/` — проверочные скрипты Windows.
- `run.bat` — запуск программы в Windows.
